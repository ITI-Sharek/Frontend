Horizontal numbered stepper — dots connected by a fill-progress line, used above the 3-step registration form.

```jsx
<StepIndicator steps={["الدور", "بيانات الحساب", "التفاصيل"]} currentStep={1} />
```

Completed steps show a check glyph and teal fill; the active step is outlined teal; connecting lines fill teal as steps complete.
